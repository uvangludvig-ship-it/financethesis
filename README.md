# Finance thesis (BE451, autumn 2026): Alexander Fox and Ludvig Pauli Uväng

**Topic:** Did the premium pension need a sponsor? Premium-pension money versus other money in the same funds before Fondtorgsnämnden (2020-2023), anchored on Sialm, Starks and Zhang (2015, JF) and building on Dahlquist and Martinez (2015, EFM). Tutor: Michael Klug.
