Read SHORT_DECISION_SV.txt first. DECISION_SV.txt gives the independent
economic rationale; FORMAL_IDENTIFICATION.txt states the missing exclusion
restriction, tracker geometry and minimum reopening conditions.

This is a design/source review. It computes no new return, fund flow,
covariance, q0/q2 capital measure, economic prediction or inference statistic.
Only source-support metadata was counted from a previously published audit.
The counts are reproduced by audit_existing_support.py using standard Python;
the script points explicitly to the original local repository and refuses to
overwrite its first output. This is not a portable raw-data package.

SOURCE_READ_LOG.json records primary readings and failed access attempts.
INPUT_HASHES.json records previously known summaries and source metadata read.
PUBLICATION_ALLOWLIST.json is the exact public file list; the SHA256 manifest
hashes every listed file except itself. No private raw sources or full-text
source documents are included. No API, UI, email or external account was used.
