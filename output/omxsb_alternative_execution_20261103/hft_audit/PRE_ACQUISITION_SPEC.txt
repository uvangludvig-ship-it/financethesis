HFT SOURCE PILOT — 2026-11-03
Written before selecting the four event metadata records or reading any HFT outcomes.
Scope: technical source audit and one exploratory descriptive execution contrast; no thesis prose, FTN outcomes, repository edits, significance search, or causal-price claim.

Selection is fixed: reviews 2019H1 and 2023H2, addition and deletion separately; lexicographically first event_id in the original final event metadata with a mapped Stockholm ordinary-share RIC, exact dated instrument ISIN and effective date. Check final implemented status against existing correction/cancellation metadata. Do not screen on CAR, daily volume, prices, holdings changes or significance. Preserve every rejected metadata candidate and its reason. After acquisition, missing source coverage never authorizes replacing an event.

Dates: effective date ED is the first index-effective trading date. Rebalance auction date is the preceding Stockholm trading session ED-1. Fixed within-security comparison session is ED-6, i.e. six trading sessions before ED. Request next trading session ED for the rebalance price follow-up. If a symmetric auction-to-next-day contrast is used, also request ED-5; this extra session must be declared before opening price outcomes. Calendar comes from dates in the existing OMXSBGI daily series, not stock-return availability. Read calendar date/identifier only, not levels or returns.

Source gate before numeric price/volume outcomes:
1. Document source product, query, exact instrument IDs and dated mapping, venue, date coverage and raw file hashes. Confirm historical identifier validity, venue coverage and currency/unit definitions.
2. Identify source timestamp timezone from documentation, including local Europe/Stockholm DST conversion. Do not infer timezone solely from a burst around an expected clock time. Preserve original timestamps.
3. Closing-auction identification requires an explicit execution/trading-phase flag or a documented message/auction reconstruction. A fixed clock-time filter alone does not certify an auction; after-hours reported, delayed and off-book trades remain separate.
4. Determine row semantics: order events, book snapshots, one match, two counterpart legs or aggregated trades. Establish the documented unique execution/match key, cancellation/correction/reversal link and trade status. Never sum multiple message legs or assume duplicates are independent executions. Retain counts of exact duplicates, conflicting keys, corrections and unmatched reversals; unresolved material ambiguity blocks volume and execution-price summaries.
5. For order-book quotes, require valid positive uncrossed bid/ask and documented sequence ordering. Audit actual coverage, empty/missing intervals, nonmonotonic and duplicate timestamps, anomalous sessions/halts and auction completeness before any summary. Missing remains NA, never zero volume or zero premium.
6. A matching index event does not identify buyer/seller, fund, trader intent, market-wide volume, or causal index trading. A reconstructed Nasdaq order book alone cannot establish total market activity.
7. Check splits, dividends, redenominations and other mechanical price changes between compared sessions using existing metadata or primary notices. Block a raw cross-day price contrast if adjustment is unresolved. Do not select replacements based on this gate.

Primary contrast will be locked once schema/auction and session definitions are established, but before inspecting computed prices or volumes. Preferred single scalar: direction-signed difference between closing-auction-to-next-session early-midquote dislocation on ED-1 and on the fixed ED-6 session. This needs ED-5 as well as ED. Exact quote window and auction selection must be fixed from documented session semantics, not empirical price patterns. Direction +1 addition, -1 deletion. It is a descriptive paired measure of unusually temporary closing dislocation, not tracking-fund implementation shortfall. With only four purposively fixed events/two reviews, report event values and coverage, no significance tests, selected windows, causal elasticities, or population-power claim.

Fallback is source-only completion if auction/match/quote semantics cannot be validated. No alternative outcome will be promoted after a failed primary source gate. Raw licensed numerical trades/quotes remain private; publication may contain scripts, query metadata, hashes, source checks and permitted derived summaries only.
