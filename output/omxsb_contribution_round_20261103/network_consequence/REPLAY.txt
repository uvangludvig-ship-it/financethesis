This folder is a baseline-only feasibility artifact, not a return test.
No repository files were edited. No FTN outcome was accessed.

Python packages: numpy, pandas, scipy, pyarrow. Only numpy and pandas are needed
for the baseline gates. pdftotext is needed only to redownload/extract PDF sources.
Original environment versions are recorded in requirements.txt.

The local repository path is explicitly set at the start of design_and_gate.py,
audit_gate.py and complete_identities.py; change it only to locate identical inputs.
Input hashes are in INPUT_SHA256.json and repair_round/INPUT_SHA256.json.

Replay in this folder, using its .venv/bin/python or a compatible Python:
1. python design_and_gate.py
2. python audit_gate.py
3. python fetch_identity_sources.py  (existing originals are not overwritten)
4. python complete_identities.py
5. python repair_round/design_and_gate.py
6. python repair_round/audit_gate.py

Keep first_gate/ immutable. Timestamps change on replay; numerical gates should
not. The completion script writes a new peer identity pool only and does not
rematch target/control stocks, relax thresholds, or open prices. It also writes
the copied rerun scripts and preserves the original design-lock timestamp.

The data acquisition log distinguishes current issuer RIC information from dated
Nasdaq ISIN/class information and actual corporate-action identity chains.
No direct name-only or price-series matching was used.

No prices/return outcomes are distributed. The large baseline_transferable_rows
files cache public FI holdings and can be regenerated from their hashed input.
The .venv directory is an execution environment, not a research deliverable.

Raw source URLs, retrieval UTC and SHA256: identity_sources/manifest.json.
Final source/output file hashes, excluding .venv: ARTIFACT_SHA256.json.
