Estimator to lock before risk work:
For each actual matched endpoint t, let A(c,t) be class TNA converted to SEK and I(c,t) its SEK total-return index (returntype=1). For the union of classes belonging to FundId during the month:
Fhat(F,t) = sum_c [ A(c,t) - A(c,t-1)*I(c,t)/I(c,t-1) ].
fhat(F,t) = Fhat(F,t) / sum_c A(c,t-1).
This equals a fund-total residual using the beginning-capital-weighted class return. It is exact aggregation of class residual ESTIMATORS, not exact observed cash flow. A representative-class return applied to total fund TNA is an approximation: fees, distributions, hedging and changing class weights can matter.

Minimal D source-presence gate, fund-month then all 24 intervals:

FundId identifies the portfolio; multiple currency streams and repeated fund-TNA fields are not extra assets. Keep the dated active union, including classes opening/closing inside the interval. Existing historical identity/full-class-universe limits remain; a present-day master alone is not exhaustive historical certification.
2. A class demonstrably not yet operating at the beginning endpoint has structural A(c,t-1)=0. Its return ratio is not required for that zero-weight term; do not manufacture a pre-inception TRI. Require its actual ending class TNA and dated entry evidence. From its first positive beginning endpoint onward require its own total-return data at both actual endpoints. A genuinely closed class may have structural ending zero only with dated closure/transfer evidence. An ordinary missing TNA or report is NEVER zero. Fund-level fields copied onto a not-yet-existing class are irrelevant to class activity.
3. Convert each positive class TNA at its actual valuation date using a documented SEK-per-class-currency rate; match SEK TRI for the same interval. A supported alternative is base-currency class TRI plus identically dated FX conversion of the return. Do not mix NOK TNA with SEK returns. Do not derive absolute FX from two normalized index levels without a documented common normalization. Currency-specific hedging is not removed by currency conversion: use the actual class's return.
4. Sum distinct class capital and reconcile to ONE contemporaneous fund-TNA observation in fund currency converted consistently. Preserve the earlier 0.99–1.01 reconciliation and <0.001 relative repeated-fund-TNA spread as provisional source tolerances; do not tune them using any risk result. Reconciliation supports coverage but does not prove the historical class universe is complete. Require positive fund starting capital.
5. Choose the last common valid valuation endpoint on/before month end for all active classes and fund TNA, within the previously declared month-end tolerance; use TRI on that actual date. A calendar-month-end weekend RIP row and Friday TNA are not automatically aligned. FX may use the previous currency-trading-day close only for a verified non-trading day under one fixed convention. Stale/missing business-day FX, different valuation dates or unresolved class lineage fail D. Record the valuation and FX dates explicitly.
6. Separate D_provisional_current_master from D_dated_lineage_verified. Current-master inception plus no positive pre-inception class TNA and matching first TRI can support the former. A dated issuer creation/closure notice with exact ISIN supports the latter. Neither flag licenses economic outcomes before the root's design decision. Do not blend D into A/B/C.

What class migration does and does not imply:
Actual simultaneous transfers between two classes of the same portfolio cancel in fund-level external cash flow; neither direction is an independent fund shock. Summing all distinct class-capital residuals removes duplicate class counting. However, monthly endpoint estimates can retain migration-timing errors when classes have different period returns, e.g. different fees/hedges. A new-class ending balance is therefore not separately labelled an external subscription. Exact transfer cancellation requires transaction timing or a validated common portfolio-return/fee adjustment; daily matched class residuals reduce but do not magically eliminate the estimation assumptions. The first new-class month may be permitted as a standard endpoint-flow estimate, with this limitation, rather than falsely certified as exact cash accounting. If exact migration-neutral flows are required, that transition month needs additional evidence and must otherwise fail the exact-flow gate.
