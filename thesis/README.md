# thesis/

What the thesis is. No data, no code: those live in `data/` and `code/`.

| Folder or file | What it is |
|---|---|
| `design/THESIS_IN_PLAIN_WORDS.md` (+ `.docx`) | **Start here.** The thesis in plain words, version 2 (25 Oct): each section, what the winners did and what the losers did, which papers go where, how every table is built, who does what. |
| `design/00_VALIDATION.md` | The verdict: does the design hold up against the blind referee. |
| `design/01_DESIGN.md` | The pre-analysis plan: theory with equations, four hypotheses each tied to one table, exposure measure, abnormal-return model, inference, power, robustness. |
| `design/03_DATA.md` | What data the design needs and how to get it. Section E holds the tutor sign-off date that unblinds the FTN returns. |
| `design/thesis2_method.tex` / `.pdf` | Method note with equations, data table and work plan (14 Oct), sent to Klug. |
| `outline/thesis2_outline.md` | Section-by-section outline with page budget (33 of 40), exhibits, equations, the trap per section. |
| `outline/winners_structure.md` | How the five closest prize winners are built. |
| `outline/requirements_checklist.md` | Every formal course requirement. |
| `literature/literature_verified.md`, `references.bib` | 66 references, 52 verified, grouped by role in the paper. |
| `text/main.tex`, `text/sections/` | The thesis itself, one file per section. Written by the authors; AI may not draft thesis prose. |
| `research_2026-10-11/` | The deep-research pass of 11 to 12 Oct that chose this design (question map, anchors, blind referee, proposal). |
| `AI_LOG.md` | Course requirement: every use of AI. |

Older summaries (`Thesis_summary_by_section`, `Uppsatsen_i_sammandrag`) are in `archive/summaries_2026-10/`.
