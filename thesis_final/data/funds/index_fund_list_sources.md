# Källbeläggning: indexföljande fonder (primärkällor)

Datum: 2026-11-09. Syfte: belägga, med fondernas egna dokument (årsberättelser, informationsbroschyrer, faktablad, underrättelser, fondbolagens nyhetsarkiv, Nasdaq), vilket index varje fond följt och från vilket datum. Tredjepartskällor (Morningstar, Avanza, Nordnet) används inte som belägg. Wayback Machine var blockerad i denna miljö, liksom curl mot nordea.se, skandia.se (direkta URL-gissningar) och internetbank.swedbank.se.

Verdiktskala: BELAGD = dokument anger index och datum; DELVIS BELAGD = index belagt men startdatum/skifte delvis slutsats; EJ FUNNEN = inget dokument hittat.
