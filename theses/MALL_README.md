```

**Senast ändrad:** <datum>, <vem>

## Det som gäller
| Vad | Var | Kommentar |
|---|---|---|
| Kod och resultat | `.../` | hur man kör, vad sista raden ska säga |
| Text | `.../` | |

## Hur man kör
<kommandon>

## Historik (gäller inte)
| Datum | Mapp | Vad | Utfall eller beslut | Status |
|---|---|---|---|---|
```

Statusord:
- **AKTIV**: detta skriver vi nu.
- **VILANDE**: kan tas upp igen, inget är fel.
- **ÖVERGIVET**: valdes bort, med skäl.
- **AVSLUTAT**: klart, till exempel ämnesvalet.
