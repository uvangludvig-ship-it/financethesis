units, split/rights/redemption events, vintage and SOD/EOD conventions first.
Index Shares q are neither total listed shares nor a fund's actual holdings.

Let q^- and q^+ be original before/after Index Shares, expressed in comparable
security units after verified corporate-action adjustments. Use ONE common
price/FX vector p* to value both baskets. At unchanged tracking capital A:
  M^- = sum_i p*_i q^-_i; M^+ = sum_i p*_i q^+_i
  modeled trade shares_i / A = q^+_i/M^+ - q^-_i/M^-.
This is replication arithmetic, not observed execution. No realized return
change is needed or permitted in this source pilot. Actual fund AUM/mandate
coverage is a separate gate; amounts can initially be expressed per unit A.

First useful metadata diagnostic among retained exact securities:
  q^+_i / q^-_i, after action adjustment and removal of any verified common scale.
If every retained member has the same ratio, there is no individual index-share
shock. A denominator change generates common proportional buying/selling; raw
stock-size differences or normalization by ADV do not manufacture exogenous
stock-specific assignment. Price drift with unchanged q is not a rebalance.
