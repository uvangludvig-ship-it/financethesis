# Reproduction instructions

Two levels of reproduction are supported. The manuscript can be rebuilt from the aggregate files in this folder. Recomputing the underlying empirical estimates requires lawful access to the frozen vendor inputs listed in `thesis_final/data/FILES.csv`.

All paths below are relative to the `thesis_draft_20261112` folder. Run in a separate working copy if you want to preserve the shipped aggregate results.

## Build the exhibits and PDF

Use Python 3.12 with NumPy 1.26.4, pandas 2.2.3, SciPy 1.15.2 and matplotlib 3.10.1. A TeX installation with newtx, natbib, booktabs, graphicx, geometry, microtype, caption, placeins, fancyhdr and xurl is required.

```sh
python code/build_exhibits.py replication/thesis_final
cd manuscript
pdflatex -interaction=nonstopmode -halt-on-error main.tex
bibtex main
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

The exhibit script reads frozen aggregate results and `audit/results/`; it does not require vendor observations. The output is `manuscript/main.pdf`. Chart and PDF metadata can contain generation timestamps, so byte-identical PDF hashes are not promised after regeneration.

## Recompute the original empirical chain

1. Make a working copy of `replication/thesis_final`.
2. Obtain the 43 exact inputs from the authorized data holder and preserve the paths listed in `data/FILES.csv`. Do not substitute a current vendor download while describing it as the frozen source.
3. Install the audit's recorded Python packages, including python-docx 1.2.0 for original exhibit output. The original script may use a local office converter for its optional combined PDF; its numerical outputs do not depend on the new manuscript PDF.
4. Run `python run_all.py` from that working copy. The runner checks the input hashes, computes results and runs the inherited numerical checks. Save the log and inspect failures, rather than assuming that a process exit code alone validates the results.
5. Compare the new CSVs with the shipped outputs. Small numerical bootstrap differences and unstable sparse auxiliary intervals are documented in the audit report; do not silently overwrite the source record.

The copied original code is unchanged from commit `d2d41666ed213e4cc1f6cb382313f59c29e87ea0`. Its Swedish comments and historical declarations are preserved. `README_original.md` contains historical claims and instructions that must be read alongside the current verification report.

## Run the independent audit

After the full source inputs and required original results are available in a separate authorized copy:

```sh
python code/independent_audit.py /path/to/authorized/thesis_final /path/to/new_audit_results
```

The script imports no inherited return or inference functions. It reconstructs returns, compares means and standard errors, checks 43 input hashes, and writes aggregate audit results. It reads event-level results for the joint holdings calculation and MSCI sensitivity, which are not included in the public package. Those are generated by the full original runner.

The new extension is observational and retrospective. Successful reproduction does not upgrade its inferential status. `audit/analysis_addendum.md` records the known-results context and subsequent exclusions.

For the separate estimator cross-check, install statsmodels 0.14.2 and run `python code/verify_estimators.py /path/to/authorized/thesis_final audit/results`. The supplied validation output records 77 passing checks against alternative implementations. This supplements the 73 main audit checks.

## File identity and access

`sources/source_file_manifest.json` identifies the pinned downloaded source files. `PACKAGE_MANIFEST.csv` identifies the new package by SHA-256. The package inventory excludes itself and transient TeX/build files. External documents are linked with retrieval status and hashes when available; third-party full texts are not republished here.

Vendor data remain subject to their original licenses. No access credential is required for the included aggregate exhibit build, and no credential is bundled in this folder.
