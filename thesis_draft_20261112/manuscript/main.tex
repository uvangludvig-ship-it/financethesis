\begin{center}\large\bfseries Index Reconstitutions and Stock Returns in Sweden\end{center}
\begin{abstract}
We examine stock returns and benchmark-linked fund holdings around OMX Stockholm Benchmark reconstitutions from July 2007 through June 2026. Adapting the empirical questions of Greenwood and Sammon (2025), we distinguish a decline in average event-window returns from evidence that those returns are economically negligible. The complete return sample contains 256 additions and 215 deletions. Additions earn an average market-adjusted cumulative return of 8.52\% in 2007--2011 and 1.50\% in 2022--2026. The latest-period 95\% wild-bootstrap interval includes zero, but is too wide to establish disappearance. Across 2017--2026, the addition return is 2.15\%, with an interval of [1.01\%, 3.39\%]. Return responses coexist with more concentrated trading before implementation. Fund-holdings evidence is consistent with benchmark-related demand, but changes in reporting coverage and uncertainty in the demand denominator weaken comparisons of price-to-demand ratios. A new exploratory, fixed-cohort calculation finds a positive cumulative addition return through twenty trading days after implementation in the later decade. Neither that persistence nor the other mechanism diagnostics identifies a causal or permanent effect of index membership. The contribution is a documented Swedish adaptation that separates return patterns, measurement choices and identifying assumptions.
\end{abstract}
