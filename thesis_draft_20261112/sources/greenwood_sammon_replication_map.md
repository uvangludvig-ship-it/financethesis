# Greenwood–Sammon replication diligence

Prepared 12 November 2026. Read-only review of the Swedish empirical implementation pinned at `d2d41666ed213e4cc1f6cb382313f59c29e87ea0`. This report distinguishes verified source content from unresolved fidelity questions. It is an implementation comparison, not a claim that the US study has been computationally reproduced.

## Immediate decisions for the revised thesis

1. Present the project as a **Swedish replication and extension of Greenwood and Sammon's empirical framework**, with explicit departures. It is not an exact replication of their US sample or every estimator.
2. Remove the added `CAR = lambda Q + I + B + U` decomposition. It is not an estimated equation in the Swedish code and is not Greenwood–Sammon's organizing equation. Their organizing quantities are price response, measured demand `D`, and multiplier `M`.
3. Keep the main exposition to the return measure, the holdings-based demand measure, and the descriptive ratio `M`. Explain each in words before notation. Put inference derivations and the Fieller calculation in the technical appendix.
4. Do not say that the arithmetic sum used by the Swedish code has been verified to equal the original paper's return aggregation. The source equation says cumulative stock return minus cumulative index return; the public text does not spell out the daily compounding and first-return conventions sufficiently to authenticate the implementation. A matched-window compound-return sensitivity is needed and must be labeled as such until original code is inspected.
5. Do not equate the Swedish implementation-day label mechanically to the US date. The source takes Siblis's effective date and describes trading-day windows, but the full texts inspected do not resolve open-versus-close implementation. In Sweden, identify the first membership day separately from the preceding trading session on which funds rebalance.
6. Explain the original paper's empirical puzzle first, then ask whether that pattern appears in Sweden. Organize mechanisms around composition, anticipation, demand measurement and trading/liquidity. Do not substitute a sequence of statistical audits for that economic argument.

## What the source supports as a simple main-text explanation

The anchor study links three observable questions: how event returns change over time, how much index-tracking funds buy or sell, and which mechanisms may reconcile the two. Its motivating equation has only two substantive components: measured demand and a multiplier. The Swedish paper should first report returns, then examine measured fund trading and selected mechanisms. It should explicitly say which ingredients are adapted because the market, data and event design differ.

For the Swedish ratio, a numerical explanation is enough: on the common later-decade addition sample, mean CAR is 2.71 percentage points and observed ownership rises by 1.03 percentage points of shares outstanding; dividing yields 2.63. This is an average return per unit of measured fund buying in that sample. A structural interpretation would require additional identifying assumptions and comparable fund coverage. There is no reason to introduce a new lambda or a latent-components model to explain this calculation.

## Highest-priority unresolved fidelity checks

- Obtain the Version of Record and official replication code through authorized publisher/library access, then inspect the lines constructing each return window. This would settle arithmetic versus compound returns and inclusive-return versus baseline-close semantics. Current sources do not justify asserting exact equivalence.
- Reconcile the original US effective-date convention before comparing it with Swedish ED−1 trading. Do not infer the convention from the location of a volume spike.
- Label every Swedish sample filter and holdings measurement change as an adaptation. Decide whether a closer G&S sample/strict-tracker variant is feasible with the data already licensed.
- Never import an older numerical table into a citation to the 2025 published paper without verifying that table. The recovered manuscripts' abstract/body inconsistencies make this a concrete issue, not a hypothetical warning.
- Keep the US headline comparison modest: published additions fell from 7.4% to less than 1%; the Swedish later-decade association remains positive. This alone does not establish a statistically significant difference between countries because periods, windows, institutions and samples differ.

## Revision-team return diagnostic, communicated after this source review

The lead investigator reported same-event, same-inclusive-day calculations of 2.1526% arithmetic versus 2.1797% compound excess returns for 2017–2026 additions, and 1.4976% versus 1.4464% in the latest five-year block. These are results of the parallel Swedish audit, not figures verified in the original paper or independently recomputed in this source review. They support keeping the frozen arithmetic primary estimate while showing a transparent compounding sensitivity. A separate endpoint interpretation that uses the AD−1 closing price as the baseline produces a materially different 2.746% rather than 2.153% later-decade mean; it must remain distinct from compounding on identical included days. Neither comparison authenticates the original authors' program. The revised methods should spell out which daily returns are actually included and preserve the distinction between date labels and return intervals.
